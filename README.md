# Java Projects

A collection of Java projects and exercises from my Data Structures coursework at NYU.

## Projects

- **[course-registration-system](course-registration-system/)** — Console app for university course registration with admin and student roles, CSV import, and data persistence via serialization.
- **[binary-search-tree](binary-search-tree/)** — Binary search tree implementation with insert, find, delete, and traversal operations driven by an interactive menu.
- **[arrays-recursion-sorting](arrays-recursion-sorting/)** — Exercises on array algorithms, recursion (binary recursion, palindromes, binary representations), and implementations of six classic sorting algorithms.
- **[recursion-problems](recursion-problems/)** — Twelve recursion problems (min cost climbing stairs, jump game, and more) solved with pure recursion.
